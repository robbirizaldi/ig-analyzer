Instagram Follow Analyzer

Analyze official Instagram JSON exports locally to discover who does not follow back, fans, mutual connections, and recently unfollowed profiles. Everything is processed 100% inside this browser.

Client-Side Security Notice Analysis runs locally in browser memory. The uploaded files are never sent to an external server or stored in any database.
How to get the Instagram JSON files

Use Instagram / Meta Accounts Center to request an export of your account data. This tool needs the export in JSON format.

  1. Open Instagram and go to Profile → Menu (☰) → Accounts Center.
  2. Open Your information and permissions.
  3. Select Export your information (or Download your information).
  4. Choose Create export, select your Instagram profile, and choose Export to device.
  5. Set the format to JSON. (HTML format is not supported).
  6. Create the export and wait until Meta makes the ZIP file ready.
  7. Download and extract the ZIP. Look for the relationship JSON files: followers_1.json, followers_2.json, and following.json. You can also upload recently_unfollowed_profiles.json if available.

Note: Extract the ZIP first on your device, then select the individual .json files below.
